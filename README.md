# cs-agent-experiment

HAI 期末專案（Group 1）的實驗介面：Cognitive Sovereignty in Agentic AI。
單一 html 檔，沒有 build step，clone 下來直接開 index.html 就能跑，或用 GitHub Pages 部署。

## 怎麼用

1. 開頁面後填參與者編號、選條件（A/B）、貼自己的 Gemini API key
2. key 只存在瀏覽器 localStorage，不會上傳到任何地方
3. 照 12 步引導跑完，從右側研究者面板匯出 CSV

API key 去 Google AI Studio 拿，免費額度就夠跑實驗。

注意：這個 repo 是 public，不要把 key commit 進來。
